# Zebo.ai – AI Interview and DevOps Automation Platform

## Overview

Zebo.ai is an AI-powered interview preparation platform that generates personalized interview questions, evaluates candidate answers and provides performance reports.

This project also implements an end-to-end DevOps workflow to automate application testing, security scanning, containerization, deployment and monitoring.

## Technology Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- AI Integration: OpenRouter
- Version Control: Git and GitHub

## Planned DevOps Infrastructure

- Jenkins – CI/CD automation
- Docker – Containerization
- Kubernetes – Container orchestration
- Terraform and Ansible – Infrastructure automation
- Prometheus and Grafana – Monitoring
- ELK Stack – Centralized logging
- Trivy – Security scanning
- Blue-Green Deployment – Advanced deployment strategy
